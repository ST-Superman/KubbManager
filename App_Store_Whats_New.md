## General Guidelines for "What's New" Text

### Best Practices
1. **Keep it concise**: Focus on the most important changes
2. **Use emojis**: Make the text more engaging and scannable
3. **Highlight benefits**: Explain how changes benefit users
4. **Be specific**: Provide concrete details about improvements
5. **Use action words**: Encourage users to try new features
6. **Maintain consistency**: Use consistent tone and style

### Structure
1. **Opening**: Exciting introduction to the update
2. **New Features**: List of new functionality
3. **Improvements**: Enhancements to existing features
4. **Bug Fixes**: Issues that were resolved
5. **Technical**: Under-the-hood improvements
6. **Closing**: Encouragement to download/update

### Tone
- **Enthusiastic**: Show excitement about new features
- **Professional**: Maintain professional credibility
- **User-focused**: Emphasize user benefits
- **Accessible**: Use clear, simple language
- **Engaging**: Make users want to try new features
