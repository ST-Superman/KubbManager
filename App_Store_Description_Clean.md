# Kubb Manager - App Store Description (Clean Version)

## App Name
Kubb Manager

## Subtitle
Training Companion for Kubb Players

## Description

Master the Swedish lawn game of Kubb with the ultimate training companion!

Kubb Manager is the comprehensive iOS app designed specifically for Kubb enthusiasts who want to improve their throwing accuracy, track their progress, and elevate their game to the next level.

CORE FEATURES

Multiple Training Modes:
- 8-Meter Training: Perfect your precision throwing with customizable targets and real-time feedback
- Inkast & Blast Training: Master advanced throwing techniques with detailed round-by-round analysis
- Baseball Kubb: Experience the innovative Baseball Kubb variation created by Andy Terveer

Comprehensive Progress Tracking:
- Real-time statistics during practice sessions
- Detailed session history with accuracy trends
- Goal setting and achievement tracking
- Round-by-round performance analysis
- Training streaks and consistency metrics

Advanced Analytics:
- Accuracy trends over time
- Performance zone analysis
- Handicap calculations for competitive play
- Blast efficiency tracking
- Field performance metrics

SMART DATA MANAGEMENT

CloudKit Integration:
- Automatic sync across all your iOS devices
- Secure cloud backup of all your training data
- Seamless data recovery and restoration

Offline Capability:
- Full functionality without internet connection
- Local Core Data storage for reliable performance
- Automatic sync when connection is restored

PREMIUM USER EXPERIENCE

Intuitive Design:
- Clean, modern SwiftUI interface
- Dark mode support for comfortable viewing
- Accessibility features for all users

Built-in Guidance:

Smart Features:
